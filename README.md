 QuickNotes App

QuickNotes App is a lightweight, responsive web application designed to help users quickly capture, organize, and search their daily notes. The application allows users to categorize notes into Personal, Work, or Ideas sections, filter notes in real time using a search bar, and persist their note collection across browser sessions.

 Features
- Add Notes: Create notes with custom text and distinct categories (Personal, Work, Ideas).
- Validation: Enforces strict inputs by preventing empty submissions and capping notes at 200 characters.
- Real-Time Search: Instantly filter displayed notes based on search keywords.
- Category Styling: Visually distinguish note categories using custom card borders and background colors.
- Local Storage Persistence: Save notes locally in the browser using `localStorage`.
- Responsive Design: Optimized layout for both mobile devices and desktops using CSS Flexbox and media queries.
